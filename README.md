<h1>HYPRO</h1>

This is a simple, effective, and fast Hyprland dotfile configuration. It features a single sleek theme with a modern aesthetic, customizable wallpaper options, 
smooth animations for a fluid experience, and optimized keybindings for enhanced productivity. You can easily change the wallpaper, hyprlock, ... to suit your style.
